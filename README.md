# KantoDex

## Sobre o projeto

O KantoDex é um projeto acadêmico desenvolvido como parte do Projeto Integrador da faculdade, com o objetivo de aplicar na prática os conhecimentos adquiridos durante os estudos de desenvolvimento web.

O projeto consiste na criação de um site interativo inspirado no universo Pokémon. Para isso, utiliza HTML, CSS e JavaScript, além da integração com a [PokéAPI](https://pokeapi.co/), uma API pública que disponibiliza informações sobre os Pokémon.

Através de requisições à API, o site permite que os usuários consultem informações de diferentes Pokémon, como nome, descrição, peso, altura e tipos. Também é possível visualizar suas vantagens e fraquezas em batalhas, considerando as relações entre os tipos.

Além da consulta individual, o projeto conta com uma funcionalidade para montar um time de até seis Pokémon, exibindo suas imagens e tipos. Outra funcionalidade permite consultar e reproduzir os sons dos Pokémon, quando disponíveis na API.

O desenvolvimento do KantoDex tem como principal finalidade demonstrar a aplicação prática dos conceitos de desenvolvimento web, especialmente a estruturação de páginas com HTML, a estilização e organização visual com CSS, a manipulação de elementos e eventos com JavaScript e a integração com APIs públicas para obtenção e apresentação dinâmica de dados.

Dessa forma, o projeto busca unir aprendizado, tecnologia e entretenimento, oferecendo uma experiência interativa para explorar o universo Pokémon e consultar informações de seus personagens.
